# Security policy

The latest `main` branch and the most recent tagged release are supported. Report vulnerabilities privately through the repository's security advisory mechanism or to `security@theaihatch.example`; do not open a public issue. Include the affected version, reproduction steps, impact, logs with secrets removed, and a proposed mitigation if available.

Maintainers target acknowledgement within five business days and an initial assessment within ten business days. We coordinate disclosure after a fix or mitigation is available. Local workspace files, provider credentials, and MCP bearer tokens are sensitive local data; the project does not provide an OS-level sandbox or a hosted proxy.
