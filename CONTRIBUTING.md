# Contributing

Install Node 22, run `npm install`, and use `npm run typecheck`, `npm run lint`, `npm run test`, and `npm run build` before opening a pull request. Keep changes scoped, add a named test for each requirement, and use conventional commits.

Pull requests must describe scope, link an issue, include tests, and include a screenshot or recording for UI changes. Do not commit keys, tokens, `.env` files, or real credentials. Security issues belong in the private channel described in `SECURITY.md`.
